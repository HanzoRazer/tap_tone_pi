## Features

**Phase 2 Session Loader:**
- Reads session directory structure (grid.json, session_meta.json, derived/ods_snapshot.json)
- Validates schema versions and array lengths
- Optional WSI curve and build record auto-discovery
- Query methods: peak_response_freq(), amplitude_at_freq(), get_point_coords()

**Heatmap Widget:**
- 2D scatter plot with viridis colormap
- Dark theme matching existing widgets
- Point lookup by pixel coords for hover interactions
- Highlight/clear functionality

**Phase 2 Results Widget:**
- WSI curve plot (falls back to mean magnitude)
- Point amplitude heatmap with frequency slider
- Peak frequencies list (clickable)
- Session/grid/build metadata panel
- Comparison panel with predicted vs measured mode frequencies

**Main Window Integration:**
- File > Open Phase 2 Session... (Ctrl+2)
- New Phase 2 ODS tab in chart area
- Error handling with dialog messages
