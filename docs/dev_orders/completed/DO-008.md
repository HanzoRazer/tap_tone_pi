## Features

**Build Record Auto-Discovery:**
- Loads BuildRecord from BuildDatabase when session has build_id
- Shows "Build: {id} ({design})" in build label
- Silent on miss (no build record found)
- Logs warning on corrupt build record without blocking

**View Menu Toggle:**
- View > Auto-discover build context (default ON)
- Toggles _auto_discover_enabled flag
- In-memory only (no persistent settings)
