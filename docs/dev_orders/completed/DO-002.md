## Key design decisions

**1. Normalization convention.** Both predicted and measured amplitudes are
normalized so peak |amplitude| = 1.0 before comparison. This makes residuals
interpretable as fractions of peak amplitude.

**2. Phase consistency via doubled-angle method.** A perfect standing wave has
phases clustered at two values 180 deg apart. We detect this by doubling the
phase angles (maps both clusters to the same point) and computing the mean
resultant length.

**3. Nodal line match via Jaccard similarity.** Points with |amplitude| < 0.1
are considered nodal. The match score is the intersection over union of
predicted and measured nodal point sets.

**4. PointSpectrumLike protocol.** Avoided hard import from scripts/phase2/ by
using duck typing. Any object with the required attributes works.
