## API surface

```python
from tap_tone_pi.materials import (
    # Dataclasses
    FlitchRecord, PlateMeasurement, SpeciesStats,
    # Database
    WoodDatabase,
    # Helpers
    is_known_species, normalize_species_freetext,
    flitch_to_dict, flitch_from_dict, validate_flitch,
    get_db_path,
    # Exceptions
    FlitchNotFoundError, DuplicateFlitchError, InsufficientDataError,
)

# Basic usage
db = WoodDatabase()  # uses ~/.tap_tone_pi/wood_db.json
db.load()
db.add_flitch(FlitchRecord(
    flitch_id="SITKA_2026_PACIFIC_001",
    species_id="spruce_sitka",
    created_at_utc="2026-05-02T12:00:00Z",
))
db.add_measurement("SITKA_2026_PACIFIC_001", PlateMeasurement(...))
db.save()

# Queries
flitch_ids = db.list_by_species("spruce_sitka")
stats = db.get_species_stats("spruce_sitka")
latest = db.get_latest_measurement("SITKA_2026_PACIFIC_001")
```

## Key design decisions

**1. Four-stage atomic commits.** Each stage is independently mergeable and
testable. Commit history:
- `2bfbda7` jsonschema dependency
- `fc10379` Stage A schema
- `fe98d2b` Stage B dataclasses
- `41208d9` Stage C CRUD
- `af7e74c` Stage D statistics

**2. Species ID convention.** Lowercase snake_case linking to wood_species.json.
Free-text normalization for legacy data ingestion. Unknown species warns but
allows construction (species database may update before flitch db).

**3. GUM uncertainty fields.** Uses degrees_of_freedom and coverage_factor
matching UncertaintyBudget convention (per user verification), not
confidence_level_percent.

**4. Schema registered.** Added to contracts/schema_registry.json with owner
"measurement-team" and status "stable".
